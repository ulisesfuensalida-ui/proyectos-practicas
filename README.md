**Alumno:** Ulises Nahuel Fuensalida
**Comisión:** 7

## Descripcion del proyecto

Portfolio personal de una sola página (single page) desarrollado con React y
Vite como Trabajo Practico N.º 1 de la cátedra. La aplicación está dividida
en componentes reutilizables (Header, Hero, About, Skills, Projects,
ProjectCard y Footer) y aplica los conceptos vistos en clase: props, arrays
renderizados con `map()`, `key`, eventos, `useState` y renderizado
condicional.

## Tecnologias utilizadas

- React 18
- Vite
- JavaScript (ES6+)
- CSS3

## Instalacion

1. Cloná el repositorio:
   ```bash
   git clone https://github.com/<tu-usuario>/tp1-react-portfolio-apellido-nombre.git
   ```
2. Entrá a la carpeta del proyecto:
   ```bash
   cd tp1-react-portfolio-apellido-nombre
   ```
3. Instalá las dependencias:
   ```bash
   npm install
   ```

## Ejecucion local

```bash
npm run dev
```

Luego abri en el navegador la URL que indica la consola (por defecto
`http://localhost:5173`).
